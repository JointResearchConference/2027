* GitHub Pages Deployment

A GitHub Actions workflow (=.github/workflows/pages.yml=) automatically builds and deploys the site on every push to =main= or =master=.

*One-time setup:*
1. Push this repository to GitHub.
2. Go to *Settings → Pages* and set the build source to *GitHub Actions*.
3. Push to =main= to trigger the first deployment.

The workflow installs Pandoc, runs =build.sh=, and deploys the =_site/= directory.

* Template & Styling

The shared HTML layout is in =templates/page.html= (a Pandoc template). It includes the left sidebar navigation, hero section (home page only), page banner, and footer. Styling is in =assets/css/style.css=.

Org-mode headings (=* Heading=) become =<h2>= elements in the output (shifted by one level so the template's =<h1>= takes precedence). Use =** Subheading= for =<h3>=, and so on.

* Org-mode Authoring Notes

- Use =* Heading= for top-level sections within a page (renders as =<h2>=)
- Use =** Subheading= for subsections (renders as =<h3>=)
- Bold: =*text*= — note: always leave a space before =\\= on the same line, i.e. =*text* \\= not =*text*\\=
- Links: =[[url][label]]=
- Line break: =\\= at end of line
- Tables: standard org-mode pipe syntax
- Code blocks: =#+BEGIN_SRC lang= ... =#+END_SRC=
- Blockquotes: =#+BEGIN_QUOTE= ... =#+END_QUOTE=

To *add a new page:*
1. Create =slug.org= at the repo root with =#+TITLE: Page Name=
2. Add the page to the =PAGES= array in =build.sh=
3. Add the nav link to =templates/page.html= (sidebar and footer)
